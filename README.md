# 🏰 Tavern Master - In-Game Mod & Trainer Menu v1.0 (macOS & Windows)

Mod Menu interaktif in-game untuk game **Tavern Master** (v1.0 Release). Menyediakan menu GUI lengkap dengan tombol switch **ON / OFF** independen untuk setiap fitur, tombol aksi cepat, kartu kontras gelap, dan kontrol kecepatan game.

---

## 🎮 Cara Menggunakan di Dalam Game

1. Jalankan game **Tavern Master** seperti biasa (melalui Steam atau Finder).
2. Di pojok kiri atas layar akan muncul tombol:
   ```text
   [⚡ TAVERN MOD]
   ```
   * Klik tombol tersebut **ATAU** tekan tombol **`F1`** / **`~` (Backquote)** pada keyboard untuk membuka/menutup menu.
3. Anda bisa menggeser (drag) jendela menu ke posisi mana saja di layar.

---

## 🛠️ Daftar Fitur Mod (Bisa Diatur ON / OFF Bebas)

### 1. 💰 Tab Ekonomi
* **[ON / OFF] Infinite Money**: Otomatis menjaga saldo koin di angka 999,999 Gold.
* **Aksi Cepat**:
  * `+20,000 Gold`
  * `+100,000 Gold`
  * `+1,000,000 Gold`

### 2. 👨‍🍳 Tab Karyawan (Waitress, Bartender, Chef, Scientist)
* **[ON / OFF] Staff God Mode**: Mood karyawan selalu 100%, stamina tidak pernah habis, tidak lelah, dan tidak akan resign.
* **[ON / OFF] Staff Super Speed**: Kecepatan jalan, membawa nampan, memasak, dan menuang minuman meningkat drastis.
  * Terdapat **Slider Kecepatan** dari `1.5x` hingga `6.0x`.
* **Aksi Cepat**:
  * `Naikkan Semua ke Level 9 (Max)`
  * `+1 Level Semua Karyawan`

### 3. 👥 Tab Tamu
* **[ON / OFF] Infinite Patience**: Waktu kesabaran tamu di-freeze. Tamu tidak akan pernah marah menunggu makanan/minuman dan tidak akan walkout.
* **Aksi Cepat**:
  * `Beri 1,000 Tamu untuk Riset` (Langsung memenuhi kuota tamu riset).

### 4. 📦 Tab Persediaan & Operasional
* **[ON / OFF] Infinite Ingredients**: Semua peti makanan (daging, sayur, roti, keju, dsb.) selalu terisi penuh.
* **[ON / OFF] Infinite Drinks**: Semua barel bir, anggur, mead, teh, jus di bar tidak pernah habis.
* **[ON / OFF] Auto Clean Tables**: Piring dan meja kotor otomatis langsung dibersihkan.
* **Aksi Cepat**:
  * `Isi Penuh Semua Peti & Barel Sekarang`
  * `Max Semua Level Makanan (Food XP)`

### 5. ⚡ Tab Riset & Kontrol Waktu
* **🔓 Buka Semua Riset (Unlock All Tech)**: Membuka seluruh skill tree dan resep riset seketika.
* **⏩ Game Speed Multiplier**:
  * Tombol preset: `1x (Normal)`, `2x (Cepat)`, `5x (Sangat Cepat)`, `10x (Ultra Fast)`.
  * **Slider Kecepatan Real-time** (`1.0x` - `10.0x`).
* **⏭ Lewati Hari (Skip to End of Day)**: Langsung memajukan waktu ke jam tutup kedai / akhir hari.

## 🔄 Manajemen Mod (Install & Uninstall)

* **Kembali ke versi asli (Vanilla / Tanpa Mod)**:
  ```bash
  ./uninstall.sh
  ```
* **Pasang ulang / Compile ulang mod**:
  ```bash
  ./install.sh
  ```
